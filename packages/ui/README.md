# @openline/ui

Design system components (built on shadcn/ui + Tailwind). Populated in Sprint 1 once the designer
delivers the base tokens (colour, type, spacing).

Rules:

- One component per folder: `button/button.tsx`, `button/button.test.tsx`, `button/index.ts`.
- Every component meets WCAG 2.1 AA (contrast, keyboard, focus states, labels).
- No business logic here — only presentation.
